# SUNASIRO CONSULTANCY — Website

Production-ready, single-page modern website for **SUNASIRO CONSULTANCY**.

## Features

- **Sticky header** with transparent-to-solid transition
- **Hero** with dual CTAs and trust signals
- **Bento-style services overview** (8 service cards)
- **Detailed accordion sections** for every service line with full deliverables
- **About**, **Industries/Clients**, **Resources/Tools**, **Insights teaser**
- **Contact form** with service interest dropdown
- **Floating WhatsApp button**
- **Scroll progress bar** + reveal-on-scroll animations
- Fully responsive, accessible, modern 2026 aesthetic
- Color system: deep navy + soft teal + warm sage + cream
- Typography: Plus Jakarta Sans (display) + Inter (body)
- Imagery featuring diverse African professionals

## Live Site

https://sunasiroconsultancy.vercel.app

## How to use

1. Open `index.html` in any modern browser, or
2. Serve locally:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```

## Tech

- Pure HTML + Tailwind CSS (CDN) + vanilla JS
- Lucide icons
- Unsplash photography featuring African professionals
- No build step required

## Customisation notes

- Replace placeholder phone/email/WhatsApp number
- Swap Unsplash images for brand photography
- Connect the contact form to your backend / Formspree / Netlify Forms
- Add real client logos when available
